{# Search by query image — browser side. Three entry points feed one upload path: the "Find by image" button in the search row (file picker), drag-and-drop of a file anywhere on the browse page, and pasting an image from the clipboard. The upload (`POST /api/query-image`, raw body) returns a session token; the page rewrites the q field to `similar:@ …` and fires the normal htmx search, so every existing filter combines with it and the grid renders its usual similarity view (single page, score badges). The query pill in the saved-searches row shows the thumbnail and filename, and survives reloads: on load / popstate / after every results swap the token in q is looked up via GET /api/query-image/{token}; a 404 means the server-side session expired and the pill says so. #}
